# 旅行電量報 · Travel Power Gazette

把旅行中的精力当成一块电池来记账：每件事消耗多少、回血多少，当天还剩几格电。

🔗 **在线使用**：<https://gavinduan.github.io/travel-power-app/>

零构建、纯静态，打开即用，不需要安装任何依赖。

## 功能

| 视图 | 说明 |
|---|---|
| 01 行程 | 建档：名称、目的地、起止日期、每日初始电量。卡片显示平均余量，可删除行程（二次确认）。 |
| 02 每日记账 | 按天记支出与回血，实时显示剩余电量、电量曲线、当日备注。常用条目可点选。 |
| 03 行程模板 | 把典型的一天存成模板，套用到任意一天，自动生成整套条目。内置 4 个模板。 |
| 04 统计报表 | 平均余量、总支出/回血、低电日警告、逐日电量柱状图、Top 消耗与 Top 回血排行。可导出 PDF 报告。 |
| 05 支出词库 | 记账可选项，负数为支出，正数为回血。内置 20 条，可自行增删。 |

快捷键：`Ctrl/Cmd + N` 跳到新建行程。

## 数据

**所有数据只保存在你自己浏览器的 localStorage 里**（键名 `travel-power-gazette-v1`），不会上传到任何服务器。

- 清浏览器数据、换浏览器、换设备都会丢数据
- 侧栏「导出全部数据 (JSON)」可备份，建议定期导出
- 侧栏「数据保存在本浏览器」可查看具体存储位置

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://127.0.0.1:8000
```

直接双击 `index.html` 也能用，但建议走 http（字体与 PDF 组件的跨域行为更稳定）。

## 技术说明

- 无框架、无构建，`index.html` + `styles.css` + `app.js` 三个文件
- 图表为手写内联 SVG，不依赖图表库
- PDF 导出用 [html2pdf.js](https://github.com/eKoopmans/html2pdf.js)（CDN 引入），后台生成独立排版文档，不走系统打印对话框
- `app.js` 中的 `store` 有一层 `window.api` 兜底，用于兼容早期的 Electron 版本
